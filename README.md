# Kiss.photography

Public marketing site for [Kiss.photography](https://kiss.photography): identity reconstruction, ranked outputs, and waitlist signup. Built with Next.js 14 (App Router), Tailwind CSS, Framer Motion, and Radix primitives.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — local dev server  
- `npm run build` — production build  
- `npm run start` — run production build  
- `npm run lint` — ESLint
